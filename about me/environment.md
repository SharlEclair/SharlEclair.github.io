# Physical Workspace (The 2 AM Setup)
* **Current Hardware:** Primarily operates from a laptop + mouse setup.
* **Previous Hardware Setup:** Custom-built desktop PC featuring a mechanical keyboard (selected for actuation curves and tactile travel) and a minimal, stealth-black aesthetic with highly restrained RGB lighting.
* **Desk Artifacts & Totems:**
  * **Rubik's Cubes:** Physical permutation puzzles for tactile thinking.
  * **Yoru Butterfly Knife Comb:** Used for kinetic fidgeting, flipping, and balance.
  * **Valorant Wingman Plushie:** A small, goofy mascot that provides a deadpan, playful contrast to the otherwise serious and technical workspace.

# Digital Environment & Tooling
* **Knowledge Management:** Heavy reliance on **Obsidian**. Uses it as a "Second Brain" to maintain local-first, markdown-based records linked via semantic tagging.
* **Automation:** Writes custom Python workflows to pipe external data (like video transcriptions and media files) directly into local markdown vaults.
* **Command Line Tools:** Prefers terminal interfaces; configured local configuration parameters for the Google Antigravity CLI. 
* **Data Stack:** Python, R, DuckDB, Polars, sqlglot, LangGraph, and various generative AI APIs (Gemini).
